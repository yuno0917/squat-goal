# スクワット伸び計算機

今のスクワットのMAXと体重から、何週間で何kg伸びるかを研究データで予測する Web ツールです。公開先は https://yuno-lab.com/squat-goal/ です。

- 体重比（MAX ÷ 体重）から、研究で見られた1週あたりの伸びの幅を出す
- 目標（+◯kg）に届くかを判定し、必要な週数の目安を出す
- 4〜16週間のスクワットメニュー（基礎→筋力→仕上げ→測定）を作る
- 入力はブラウザ内だけで処理し、サーバーには送信しない

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・予測・判定・メニュー・よくある質問・免責 |
| `evidence.html` | 根拠にした研究のまとめと計算方法 |
| `tests.html` | ロジックのテスト（ブラウザで開くと結果を表示） |
| `js/sq-data.js` | 研究の数字、伸びの幅、メニューの設定値 |
| `js/sq-calc.js` | 予測・判定・メニュー作成のロジック |
| `js/sq-chart.js` | グラフ（SVG） |
| `js/app.js` | フォーム・描画・保存・共有リンク |

研究の数字や伸びの幅を変えたら `tests.html` を開き、テストがすべて通ることを確認してください。`evidence.html` と `index.html` の表の数字も合わせて直します。
